Modifications: package/model relocation, exclusion of Telegram protocol
serialization, HDR/video/UI blur input APIs and optional skin smoothing/private
tone mapping; Android lifecycle/logging adapters; injected size policy; headless
EGL pbuffer; dedicated calcCDT JNI binding; input/buffer/lifecycle safety checks.
See docs/extraction-manifest.json and provenance/ for URLs, Git blobs, output
hashes and private full-patch hashes. Full excluded originals and deletion diffs
are not part of this distributable source package.

The optional smoothing/private tone-mapping block was conservatively omitted:
research found recognizable Yu Ao MIT smoothing and Brad Larson GPUImage BSD-3
lineage, but did not establish the immediate Java port chain. Their implementation
is not included or replaced. A deprecated state compatibility field is rejected
when nonzero and does not enable that feature. User adjustment curves from the
separate PhotoFilterView model remain retained under their preserved GPL notice.
